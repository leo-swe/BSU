Требования к имени класса css
 класс не должен начинаться с цифры;
 класс не должен содержать русские буквы, только латинские;
 в имени класса допустимо использовать дефис (-) и

подчёркивание (_) — .view-design-block
и .search_form_button для примера;
 класс можно начинать с дефиса и подчёркивания — .__error__

для примера;

 классы чувствительны к регистру — .Red, .RED и .red — это всё

разные имена.

Идентификаторы
CSS
#tagline{ color: orange;}
HTML
<h1 id="tagline">Этот заголовок будет оранжевым.</h1>

В отличие от классов каждый идентификатор должен быть уникален,
иными словами, встречаться в коде документа только один раз.

Признаки идентификаторов и классов CSS

Идентификатор

Класс

1. В коде документа каждый идентификатор
уникален и должен быть включён лишь
один раз.
2. Имя идентификатора чувствительно к
регистру.
3. Через метод getElementById можно
получить доступ к элементу по его
идентификатору и изменить свойства
элемента.
4. Стиль для идентификатора имеет
приоритет выше, чем у классов.

1. Классы могут использоваться в
коде неоднократно.
2. ​Имена классов чувствительны к
регистру.
3. ​Классы можно комбинировать
между собой, добавляя несколько
классов к одному тегу.

Резиновый макет
Резиновый тип макетов называют тянущимся, так как контент

структурных элементов относительных показателей.

ширину устройства.

% + media-queries

px + % + media-queries
