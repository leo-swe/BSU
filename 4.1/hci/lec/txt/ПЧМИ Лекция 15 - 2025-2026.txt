Синтаксис Sass: расширения


Расширения предоставляют
возможность легко обмениваться и
повторно использовать стили без
явного повторения кода или
включать дополнительные классы,
предлагая идеальный способ
сохранить модульность кода.
 Элементы и классы могут быть
использованы в качестве
расширения, также есть селекторзаполнитель, построенный
специально для расширений.
 Расширения устанавливаются с
помощью правила @extend, за
которым следует селектор для
расширения.
 Применяются с OOCSS и
SMACSS.

CSS-постпроцессоры
PostCSS:
 это не препроцессор стилей, как Sass или Less
Он не определяет пользовательский синтаксис и семантику, фактически это
не язык. PostCSS работает с CSS и может быть легко интегрирован с
описанными выше инструментами. При этом любой допустимый CSS может
быть обработан с помощью PostCSS.
 это инструмент для преобразования синтаксиса CSS
Позволяет определять пользовательский синтаксис, подобный CSS,
который может быть понятен и преобразован с помощью модулей
(расширений). При этом PostCSS относится не только к спецификации CSS,
но и к способу определения синтаксиса CSS. Позволяет определить
пользовательские синтаксические конструкции, такие как @правило (atrule).
 является важным инструментом в экосистеме CSS
Большое количество инструментов, таких как Autoprefixer, Stylelint,
CSSnano, были созданы на основе экосистемы PostCSS.

Программное средство для проектирования веб-интерфейса
Программное средство или фреймворк (framework) — программное
обеспечение, облегчающее разработку и объединение разных компонентов
большого программного проекта.
Программное средство или фреймворк — это инструмент, который
предоставляет общие функциональные возможности для различных проектов,
имеет согласованный API и структуру именования, которые позволяют быстро
запускать и выполнять задачи независимо от проекта.
Программное средство для проектирования веб-интерфейса или вебфреймворк — это группа готовых веб-компонентов и моделей, которые
облегчают веб-программирование и представляют его более организованным.
 Программные средства для разработки веб-интерфейса (css-фреймворки и
js-фреймворки) — клиентская часть (frontend).
 Программные средства для реализации логики фреймворк — серверная
часть (backend).

Программное средство для проектирования веб-интерфейса
Классификация по уровню абстракции:
 Основанные на запросах: программное средство (фреймворк)
непосредственно обрабатывает входящие запросы. Сохранение состояния
происходит за счёт серверных сессий. Примеры: Django, Ruby on Rails,
Struts, Grails.
 Основанные на компонентах: программное средство (фреймворк)
абстрагирует обработку запросов внутри стандартных компонентов и
самостоятельно следит за состоянием. Своим поведением данные
фреймворки напоминают стандартные программные графические
интерфейсы. Примеры: JavaServer Faces, Tapestry, Wicket.
 Rich Internet Application-фреймворк: служат для разработки полноценных
приложений, запускаемых внутри браузера. Пример: Apache Flex.
 Проектирование веб-интерфейса: программные средства для реализации
элементов пользовательского интерфейса из готовых компонентов,
реализованных с помощью html, css, javascript.

Программное средство CSS
Программные средства отличаются друг от друга и имеют разные
подходы, но у них общие цели:
 Ускорить процесс разработки, за счет уничтожения привычных

правилам дизайна.
 Корректно выровнять все элементы на странице.
 Сделать подключаемые к приложению стили более удобными с

точки зрения поддержки.

Bootstrap

Bootstrap
 Набор модулей (расширений) JavaScript, которые размещаются в

каталоге js/dist/*.js, или все модули в одном файле
bootstrap.js (bootstrap.min.js).
 Bootstrap CSS может использоваться в любом другом

программном средстве (фреймворке).
 Bootstrap JavaScript не совместим полностью с рядом

программных средств JavaScript, например React, Vue и Angular.


Рекомендуется использовать специальный пакет Bootstrap для каждого из
JS программных средств, например:


React: React Bootstrap



Vue: BootstrapVue (Bootstrap 4)



Vue 3: BootstrapVueNext (Bootstrap 5, currently in alpha)



Angular: ng-bootstrap

https://getbootstrap.com/docs/5.3/getting-started/introduction/
